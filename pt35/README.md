# CollarPet PM35/PT35 Integration Bundle

This folder contains the latest synced PM35/PT35 scripts from the `temp resurces/current/pt35` bundle.

## Included

- Desktop launchers in `Desktop/`
- Update/install helper scripts in `Desktop/Collar_Pet/`
- Dashboard and BLE link tools in `link/`
- PT35 download bundle artifacts in `Downloads/`
- PT35 keyboard firmware source in `keyboard/`
- PetMind training UI launcher in `training/`
- PT35 handoff scripts in `scripts/`
- PM35 terminal command reference in `PM35-README.txt`

## Not included on purpose

- Local virtual environments
- Runtime state files
- Backup snapshots under temporary folders
- Temporary embedded SDK clones and temporary `.git` folders from export bundles

Use the scripts as deployment/update helpers on the target PM35/PT35 system.

For keyboard-specific documentation, see `Downloads/README.md` and `keyboard/README.md`.

For PetMind handoff scripts, see `scripts/`.
